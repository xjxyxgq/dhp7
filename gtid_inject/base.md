用于根据用户需求向目标MySQL数据库注入空事务。

首先用户需要提供：待注入的数据库的地址、用户名、密码，用于获取数据库当前的 gtid sets 和对数据库进行空 gtid sets 注入操作。

待注入的目标 gtid sets 来源有两种：
1. 用户明确说明，会以 mysql gtid sets 的格式给出，这个 gtid sets 是目标的最终 gtid sets，程序需要解析待注入数据库当前的 gtid sets 和提供的目标 gtid sets 的差异并对差异部分进行注入
2. 用户提供目标数据库的地址，可能会是多个 mysql 服务地址，链接上去获得每个节点的 gtid sets，全部合并为一个作为目标最终 gtid sets，然后依然将这个目标 gtid sets 与待注入数据库的 gtid sets 做差异比较并注入

操作方式支持两种，交互式和非交互式，默认为交互式，会告知每一步获取到的、解析到的 gtid sets结果，并在进行注入前获取用户确认。非交互式则会直接进行注入操作，但输出交互过程并自动确认。

实现的另一个核心要素是并发度，默认每个线程执行同一个 gtid 的 500 个事务注入，500 个作为参数可调，整体的并发度默认为 10，也调。程序应当确保在并发情况下注入的 gtid sets 完整。注入后进行完整性检查。
